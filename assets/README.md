# Assets

## CSS
The complete shared stylesheet is in `assets/css/style.css`.

The CSS is formatted line-by-line so each selector, property, value, layout rule, responsive rule, and reusable class can be clearly read and edited.

## Images
The `assets/images/` folder contains local SVG illustrations used by the practical pages. They work without needing an external image URL.

Files:
- `web-tech.svg` — Web technology illustration
- `portfolio.svg` — Portfolio/profile illustration
- `gallery-1.svg` to `gallery-4.svg` — Gallery demonstration images
